# 난로

벽난로가 있는 오두막 서재를 1인칭으로 걸어 다니다가, 의자에 앉아 실제 책 같은 ebook을 읽는 3D 공간입니다.
브라우저에서 돌아가며 WebGPU를 씁니다.

전체 계획은 기획서(11장 개발 단계)를 따릅니다.

## 실행

```bash
npm install
npm run dev
```

http://127.0.0.1:5320 을 Chrome 또는 Edge로 열고 화면을 클릭합니다.

| 키 | |
|---|---|
| `W A S D` / 방향키 | 걷기 |
| 마우스 | 둘러보기 |
| `E` 또는 클릭 | 바라본 물체와 상호작용 (의자에 앉기, 장작 넣기, 불 뒤적이기, 스탠드) |
| `Shift` / `Ctrl` | 천천히 걷기 / 쭈그리기 |
| 앉은 뒤 `E` / `Space` | 책 펼치기 / 책 덮기·일어나기 |
| `O` | 설정창 (불 그래픽, 볼륨) |
| `F3` | 성능 표시 (fps, 불 격자, 광량 신호) |
| `[` `]` | 전체 볼륨 내리기, 올리기 (임시. 채널별 소리 설정 화면은 6단계) |
| `Esc` | 마우스 풀기 |

`O` 키나 시작 화면의 "설정" 버튼으로 설정창을 엽니다. 불 그래픽은 프리셋(가벼움, 균형, 낮음, 중간, 높음, 최고)을 고르거나 격자 칸 수, 시뮬레이션 속도, 압력 계산 반복, 픽셀 밀도, 선명화 같은 항목을 표시된 최소와 최대 사이에서 직접 넣을 수 있습니다. 값은 브라우저에 저장되고, 격자처럼 다시 만들어야 하는 항목은 "적용"을 누르면 화면을 다시 불러옵니다. 기본값 "균형"은 Intel Arc B390에서 60fps, GPU 사용률 약 50%로 잰 값입니다(측정 기록: `docs/phase1/`).

주소 옵션: `?q=light|balanced|low|medium|high|ultra` 불 프리셋, `?grid=N` 격자 가로 칸, `?fq=키:값,…`와 `?rp=키:값,…` 항목 덮어쓰기(측정용, 범위 제한 없음), `?nofire` 불 끄기(대체 표시), `?webgl` 방을 WebGL2로, `?stats` 성능 표시 켜고 시작, `?fixed` 해상도 자동 조절 끄기, `?mute` 소리 끄기.

소리는 처음 클릭할 때 켜집니다. 불 소리는 불의 세기와 불빛 변화, 벽난로까지의 거리와 방향에 따라 달라지고, 소리의 "탁" 하는 순간에 맞춰 불티가 튑니다.

## 윈도우 프로그램

브라우저 없이 아이콘으로 켜는 윈도우 프로그램으로도 만들 수 있습니다. 화면은 웹버전과 같은 코드이고, `src-tauri/` 가 그것을 창에 담습니다(Tauri, 윈도우의 Edge 엔진 WebView2 사용). 만드는 순서와 설치되는 곳은 [packaging/README.md](packaging/README.md) 에 있습니다.

- `F11` 전체 화면과 창 전환, `Alt+F4` 또는 시작 화면의 "끝내기"로 종료. 창 크기와 위치는 기억합니다.
- 책과 설정은 프로그램 폴더와 다른 자료 폴더(`C:\Nanro`)에 있어, 새 버전을 덮어 깔아도 남습니다.
- 브라우저에 넣어 둔 책과 설정은 설정창의 "파일 하나로 내보내기"로 내보낸 뒤 프로그램에서 "백업 가져오기"로 옮깁니다.
- 프로그램 안에서만 필요한 화면 쪽 코드는 `src/desktop.js` 한 곳에 있습니다.

## 2차 개선에서 달라진 점

- **방 배치**: 왼쪽 책장, 가운데 격자창, 오른쪽 돌 벽난로. 가죽 의자 두 개 모두 앉아서 책을 읽을 수 있습니다.
- **가구 옮기기**: 의자, 탁자, 스탠드, 바구니를 바라보고 `G`로 들고, 휠로 돌리고, `G`나 클릭으로 내려놓습니다(`Esc` 취소). 배치는 저장되고 설정의 "방" 탭에서 처음대로 되돌립니다.
- **액자**: 벽난로 위 액자를 바라보고 `E`를 누르면 내 이미지를 넣습니다(브라우저에만 저장).
- **읽기 자세**: 책을 무릎 담요 위에 얹고 두 손으로 잡습니다. 쪽은 1.5배 해상도로 그리고, 읽는 동안은 화면 해상도를 낮추지 않습니다.
- **읽기 자세 조절**: 읽는 중에 마우스 오른쪽 단추로 끌면 시선이 움직입니다. Shift+휠은 책 기울기, Alt+휠은 책 높이, Ctrl+휠은 확대. 책 설정(Tab)의 "읽기 자세"에서 시선, 시야각, 책 높이·거리·좌우·기울기를 숫자로 맞추고 손을 보이게 할 수 있습니다(기본은 손 없음).
- **읽는 동안 불 기록 재생**: 불빛을 60초 기록한 뒤, 불이 화면에 없으면 불 계산을 멈추고 기록한 불빛을 되풀이합니다(설정에서 끌 수 있음).
- **장작**: 화실의 장작 세 개는 타면서 검게 변하고 줄어듭니다. 벽난로 옆 더미에서 `E`로 하나씩 넣고(더미가 줄어듭니다), 더미가 비면 더미에서 `E`로 다시 채웁니다.
- **화면**: 방의 반사 환경 맵, 스탠드 그림자, 구석 음영과 빛 번짐(설정의 "실사 효과"). 주소 옵션 `?nopost`, `?noenv`로 끌 수 있습니다.
- **바깥**: 층진 전나무와 눈, 먼 숲 윤곽, 밤의 푸른 눈빛, 창턱 눈과 유리 성에.
- **사진용 견본 책**: `node tools/sample-epub.mjs` → `books/sample.epub` (새로 쓴 글). `node tools/shot.mjs demo3`이 씁니다.

## 3차 개선에서 달라진 점

- **바로 읽기**: 시작 화면의 "이어서 읽기"를 누르면 읽기 의자에 앉아 책이 바로 펴집니다. 서재가 비어 있으면 파일을 고르거나 창에 끌어다 놓으면 됩니다. "방 둘러보기"는 걸어서 들어갑니다.
- **안내**: 걷기, 앉기, 읽기 상태마다 한 줄 안내가 세 번까지 뜹니다. `H`는 전체 조작법입니다. `Esc`로 마우스를 풀면 시작 화면 대신 작은 멈춤 띠가 뜹니다.
- **가만히 있을 때 절전**: 시선이 멈춰 있으면 방을 절반 속도로(책을 읽는 동안은 3분의 1로) 그립니다. 불, 책장 넘김, 둘러보기는 그대로입니다. Arc B390에서 앉은 상태 GPU가 72%에서 57%로 내려갔습니다(`docs/round3/pc-efficiency.md`). 설정의 조작·접근성 탭에서 끌 수 있고, 주소 옵션 `?noidle`(끄기), `?idle=N`(N 프레임에 한 번, 측정용)이 있습니다.
- **화면 크기**: 방은 가로 1920픽셀까지만(읽는 동안은 2240픽셀) 그려 4K 화면에서도 60fps를 지킵니다.
- **의자, 다리, 책**: 징 장식이 없는 쿠션 의자, 바지 주름이 있는 다리, 가운데가 접히고 종이가 볼록하게 휘는 책. 책은 접힌 채 올라오며 펴지고 덮을 때 접히며 내려갑니다.
- **바깥**: 창밖 나무는 캔버스에 그린 나무 그림입니다(`src/scene/trees.js`).
- **사용 흐름 시험**: `npm run flow` (개발 서버가 켜져 있어야 함). 시작 화면부터 읽기, 넘김, 덮기, 다시 열기, 끌어다 놓기까지 실제로 눌러 봅니다.
- **화면 요소까지 찍기**: `node tools/shot.mjs room1 --dom --eval "NANRO.settings.open()"`.

## 구조

```
src/main.js            진입점: 렌더러, 임시 조명, 루프, 해상도 자동 조절
src/scene/layout.js    방 치수와 가구 배치 (미터)
src/scene/room.js      회색 상자 방, 충돌 상자, 상호작용 대상, 화구 "구멍"
src/player/player.js   1인칭 이동, 상호작용, 앉기 상태 머신
src/fire/fireLayer.js  벽난로 불 레이어 (별도 WebGPU 캔버스, 플레이어 시점과 동기화, 불빛 신호)
src/fire/vendor/       procedural-fire에서 가져온 시뮬레이션·렌더러 (MIT)
src/dev/capture.js     개발용 GPU 픽셀 캡처
tools/shot.mjs         헤드리스 스크린샷
tools/flow.mjs         사용 흐름 시험 (시작 화면에서 읽기까지)
```

불은 방과 다른 캔버스에 그려집니다. 방 캔버스는 화구 입구에 투명한 구멍을 내고, 그 아래 깔린 불 캔버스가
같은 카메라로 화구 안쪽(벽돌 벽, 장작, 숯, 불꽃)을 그립니다. 불이 내는 실제 광량이 방의 불빛 세기를 움직입니다.
