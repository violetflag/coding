# 난로

벽난로가 있는 오두막 서재를 1인칭으로 걸어 다니다가, 의자에 앉아 실제 책 같은 ebook을 읽는 3D 공간입니다.
브라우저에서 돌아가며 WebGPU를 씁니다.

지금은 **1단계 프로토타입**입니다: 회색 상자로 된 방, 걷기와 앉기, 벽난로 안의 물리 기반 불꽃.
전체 계획은 기획서(11장 개발 단계)를 따릅니다.

## 실행

```bash
npm install
npm run dev
```

http://127.0.0.1:5320 을 Chrome 또는 Edge로 열고 화면을 클릭합니다.

| 키 | |
|---|---|
| `W A S D` / 방향키 | 걷기 |
| 마우스 | 둘러보기 |
| `E` 또는 클릭 | 바라본 물체와 상호작용 (의자에 앉기, 장작 넣기, 불 뒤적이기, 스탠드) |
| `Shift` / `Ctrl` | 천천히 걷기 / 쭈그리기 |
| 앉은 뒤 `E` / `Space` | 책 펼치기 / 책 덮기·일어나기 |
| `F3` | 성능 표시 (fps, 불 격자, 광량 신호) |
| `[` `]` | 전체 볼륨 내리기, 올리기 (임시. 채널별 소리 설정 화면은 6단계) |
| `Esc` | 마우스 풀기 |

주소 옵션: `?q=low|medium|high|ultra` 불 품질(기본 medium), `?nofire` 불 끄기(대체 표시), `?webgl` 방을 WebGL2로, `?stats` 성능 표시 켜고 시작, `?fixed` 해상도 자동 조절 끄기, `?mute` 소리 끄기.

소리는 처음 클릭할 때 켜집니다. 불 소리는 불의 세기와 불빛 변화, 벽난로까지의 거리와 방향에 따라 달라지고, 소리의 "탁" 하는 순간에 맞춰 불티가 튑니다.

## 구조

```
src/main.js            진입점: 렌더러, 임시 조명, 루프, 해상도 자동 조절
src/scene/layout.js    방 치수와 가구 배치 (미터)
src/scene/room.js      회색 상자 방, 충돌 상자, 상호작용 대상, 화구 "구멍"
src/player/player.js   1인칭 이동, 상호작용, 앉기 상태 머신
src/fire/fireLayer.js  벽난로 불 레이어 (별도 WebGPU 캔버스, 플레이어 시점과 동기화, 불빛 신호)
src/fire/vendor/       procedural-fire에서 가져온 시뮬레이션·렌더러 (MIT)
src/dev/capture.js     개발용 GPU 픽셀 캡처
tools/shot.mjs         헤드리스 스크린샷
```

불은 방과 다른 캔버스에 그려집니다. 방 캔버스는 화구 입구에 투명한 구멍을 내고, 그 아래 깔린 불 캔버스가
같은 카메라로 화구 안쪽(벽돌 벽, 장작, 숯, 불꽃)을 그립니다. 불이 내는 실제 광량이 방의 불빛 세기를 움직입니다.
